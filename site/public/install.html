yakupov.xyz/install

Install 3JSxWin on Windows.

One PowerShell line. No admin, no installer wizard, no registry. It drops the app in your user folder, adds a Startup shortcut, and opens a preview window.

Download zip Back to the site

One-liner

Open Windows Terminal or PowerShell and paste:

irm https://yakupov.xyz/install.ps1 | iex

Add -StartupArgs "--span-all" after the script if you want every monitor, or run it with -NoStart to skip the preview window.

& ([scriptblock]::Create((irm https://yakupov.xyz/install.ps1))) -StartupArgs "--span-all"

What it does

  • Downloads 3jsxwin-win-x64.zip from this site
  • Extracts to %LOCALAPPDATA%\3JSxWin
  • Installs the .NET 8 Desktop Runtime via winget if it is missing (that step may prompt)
  • Creates a Startup shortcut so it comes back after reboot
  • Launches Backdrop.exe --window first so you can check the GPU before it takes the desktop

Manual zip

  1. Download the zip
  2. Unzip to somewhere without spaces or OneDrive, e.g. C:\Apps\3JSxWin
  3. Install the .NET 8 Desktop Runtime (x64) if Windows asks
  4. Run Backdrop.exe --window, then Backdrop.exe
  5. Optional: .\install-startup.ps1 -Arguments "--span-all"

Uninstall

irm https://yakupov.xyz/install.ps1 | iex
# then in a new prompt, if you saved the script:
irm https://yakupov.xyz/install.ps1 -OutFile $env:TEMP\3jsxwin-install.ps1
& $env:TEMP\3jsxwin-install.ps1 -Uninstall

Or delete %LOCALAPPDATA%\3JSxWin and the Backdrop shortcut in your Startup folder.

Needs

  • Windows 11, or Windows 10 20H1+
  • WebView2 — already on Windows 11
  • .NET 8 Desktop Runtime — the one-liner installs it if winget is available
