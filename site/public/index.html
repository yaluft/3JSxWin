yakupov.xyz · 3JSxWin

A three.js aurora living behind your Windows 11 icons.

Live wallpapers — Aurora, Tube Dunes, Starwell, Tube Warp, Ion, Tube Loops, Ember, Kelp, and Murmur — on the real desktop WorkerW layer. A console library adds worlds, machines, and Bayline (voxel Tokyo). Each scene can follow its own environment palette, or you shuffle Neovim themes. Sound is a low pad, not hiss.

Install Play scenes GitHub

What you get

  • Nine core scenes always loaded (Aurora, Tube Dunes, Starwell, Tube Warp, Ion, Tube Loops, Ember, Kelp, Murmur)
  • Optional library (Orbis, Atoll, Bayline, and more) — install from the Ctrl+Alt+B console
  • Palette randomizer seeded from real Neovim colorschemes
  • --window preview before anything touches the desktop
  • Tray icon: window/desktop toggle, reload, diagnostics, quit
  • On-scene console with live sliders and the theme library
  • Startup shortcut — no admin, no registry
  • Adaptive quality so it can sit in the background for hours

Install

On Windows, one line in PowerShell. Details at yakupov.xyz/install.

irm https://yakupov.xyz/install.ps1 | iex

Or download the zip. Developers who want to build from source still use the repo:

git clone https://github.com/yaluft/3JSxWin.git
cd 3JSxWin
.\build.ps1
.\dist\Backdrop.exe --window

Use it

Desktop mode hides the window. The tray icon is the way back. Double-click it to toggle window and desktop mode.

.\dist\Backdrop.exe --span-all
.\install-startup.ps1 -Arguments "--span-all"

Ctrl+Alt+B opens the console. SAVE writes config.json. Or hand-edit dist\web\config.json and reload from the tray.

If it goes wrong

Read %LOCALAPPDATA%\Backdrop\backdrop.log. If the scene never attaches, run .\dist\Backdrop.exe --diagnose. Close Wallpaper Engine, Lively, or Rainmeter if they already own the layer.
